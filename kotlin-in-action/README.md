# Introduction

This folder contains my Kotlin practice code and study notes.

I'm studying Kotlin primarily using *Kotlin in Action, Second Edition*, and I record what I've learned through Markdown notes and Kotlin code examples.

The study notes are written based on my personal understanding of the material, rather than as a direct translation or reproduction of the book. Some code examples are based on those provided in the book, with minor modifications or additions for practice, while others are included for further experimentation.

# Book

My primary reference is *Kotlin in Action, Second Edition*. I also refer to an earlier MEAP version of the original book.

### 1. Kotlin in Action (First Edition)

- **Authors:** Dmitry Jemerov, Svetlana Isakova
- **Publisher:** Manning Publications
- **Publication:** February 2017 (final first edition)
- **ISBN:** 9781617293290
- **Reference PDF:** [Kotlin in Action — MEAP Edition](https://github.com/ivanarandac/Books/blob/master/Kotlin%20In%20Action.pdf)

The linked PDF is an early-access version from the *Manning Early Access Program (MEAP)*, rather than the final published edition.

### 2. Kotlin in Action, Second Edition (Primary Reference)

- **Authors:** Sebastian Aigner, Roman Elizarov, Svetlana Isakova, Dmitry Jemerov
- **Publisher:** Manning Publications
- **Publication:** April 2024
- **ISBN:** 9781617299605
- **Reference PDF:** [Kotlin in Action, Second Edition](https://dokumen.pub/kotlin-in-action-2.html)

This is the main textbook used for the study notes and Kotlin examples in this repository.
